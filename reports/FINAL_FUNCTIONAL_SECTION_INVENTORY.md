# PRAHARI-AI — Final Functional Section Inventory & Provenance

This inventory catalogs every functional section, visual card, data metric, and control element present in the PRAHARI-AI Command Center, Admin Panel, and Notification Subsystem.

---

## 1. Provenance Classification Taxonomy

Every user-visible metric and data source is classified under one of the following strict categories:
* **`REAL_RUNTIME`**: Directly measured from active hardware, active inference pipeline, active OpenCV capture, or live operating system metrics.
* **`REAL_DATABASE`**: Authoritative value queried directly from persistent SQLite tables (`admin_incidents`, `anpr_events`, `intrusion_events`, `security_events`, `notifications`).
* **`REAL_DERIVED`**: Deterministically computed from real runtime and/or real database state via published system logic (e.g. system health or threat status).
* **`STATIC_CONFIGURATION`**: Declared design or configuration values (e.g. fallback labels, empty state guidance, camera identifiers).
* **`FALLBACK`**: Safe value returned during unexpected subsystem failure or disconnected channels.
* **`DEMO`**: Synthetic or illustrative data. *(None permitted in production telemetry)*
* **`HARDCODED`**: Fixed constant value masquerading as live metric. *(Flagged as DEFECT if present)*
* **`UNKNOWN`**: Metric with indeterminate origin. *(Flagged as DEFECT if present)*
